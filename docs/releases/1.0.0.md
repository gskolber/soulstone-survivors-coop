**Soulstone Coop 1.0**: online co-op for Soulstone Survivors (game version 1.5.3.2), now with a Co-op screen that looks like part of the game.

**Everyone needs 1.0.0**: it does not connect to 0.9.x. Install the same way: extract `SoulstoneCoop-1.0.0.zip` into the game folder over the previous version (Steam → right-click the game → Manage → Browse local files), then launch from Steam.

## New in 1.0

- **Native Co-op screen:** the Co-op tab now animates and highlights like the game's own menu tabs, and the panel is a pop-up in the game's style, with separate sections for Steam invites and direct IP, and a list of everyone in the lobby (up to 8) with their character's icon and name, state and ping. Esc closes just the panel.
- **Update notice:** the mod tells you in the main menu when a newer version is out, with a button to its page (it never downloads anything, and it can be turned off in the config: `[Updates] CheckForUpdates`).

## Everything the mod does

- Up to 8 players in the same run, invited through Steam (P2P relay, no port forwarding) or by direct IP.
- The host starts the run and everyone follows on the same map, mode, difficulty and curses.
- Same enemies, bosses and area warnings for everyone; everyone damages the same enemies, and enemies chase whoever is closest.
- Partners show with their own character, skin, weapon, Steam name, health bar, pets/summons and dash trail; you see their skills.
- Team XP, loot and kill credit; level-ups and other upgrade choices open as a compact panel and never pause anyone; Esc pauses everyone and the host can unpause.
- Downed state and revive by any ally; defeat only when everyone is down; victory, portals and Restart for all.
- Texts in your game's language (8 languages).

Known limitations are listed in the [README](https://github.com/gskolber/soulstone-survivors-coop#known-limitations).
