**Soulstone Coop 1.6.1**: guests can dodge with their dash.

**Everyone needs 1.6.1**: it does not connect to 1.6.0 or older. Everything in the [1.6.0 notes](1.6.0.md) is included.

## New

- **Wukong's yin-yang orbs and other heroes' drops** (ghost ship souls, elemental orbs, Mechatron, reanimation...) now show for the other players.
- **Dash dodge for guests:** a guest who dashes through an attack now dodges it like the host does, with the game's own rules (damage over time from statuses still applies). Network delay shifts the window slightly.

## Fixed

- **The host no longer pauses because of a guest:** it doesn't freeze while a guest rejoins mid-run, and its level-up choices don't switch to the solo pause when a guest leaves the run or drops (for 60 s, while they reconnect).
- **Guests could get stuck unable to level up** (empty "Behemoth Behemoth" cards) and had their match inventory reset every few seconds: a 1.6.0 change made the build backup for rejoining run the game's stage-transition step mid-run. That backup is off again.

## Known limitations

- A player who surrenders and rejoins with Fight comes back as a new character (a dropped connection keeps the build: it reconnects into the same run).
- If the host takes a portal, restarts or goes back to the menu while a guest is disconnected, the guest reconnects into the old stage. Surrender and press Fight to join the host's current run.
- The test keys (F1-F3, F5-F11, Insert, Delete, PageDown) are still active; the README lists them.
- A guest's "on dash dodge" upgrades don't trigger yet.
- The Machinist's rotating crystals still don't show on partners' screens.
